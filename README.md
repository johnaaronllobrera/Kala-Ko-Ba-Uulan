# KALA KO BA UULAN?!

This folder contains the research poster for **“KALA KO BA UULAN?!”**. The poster presents the study’s approach to examining whether entropy-based features can help anticipate the size of meteorological forecast errors.

The design keeps the original dark navy look, with teal and muted gold accents. The aim is to make the research easier to follow at a glance without turning the poster into a wall of text.

## Open the poster

Open `KALA_KO_BA_UULAN_Research_Poster.html` in a modern browser. Chrome, Edge, and Firefox should work.

Keep the `kala_ko_ba_uulan_assets` folder beside the HTML file. It contains the fonts and institutional marks used by the page. If you move the HTML file on its own, some of those elements will not load.

No installation or internet connection is needed. The poster uses local files included in this bundle.

## What’s inside

- `KALA_KO_BA_UULAN_Research_Poster.html` — the poster itself.
- `kala_ko_ba_uulan_assets/` — the Lato font files and the Institute, College, and University marks used in the design.

## A note on the research

The poster follows the framing and methods in the accompanying manuscript draft. It focuses on **anticipating absolute forecast error**, not on producing a new weather forecast. The study considers temperature, relative humidity, and precipitation, and examines entropy-based features alongside conventional time-series summaries.

The poster is a presentation of the current research draft, not a substitute for the full manuscript. For the complete rationale, definitions, methodological details, and references, consult the manuscript.

## If you need to make changes

The poster is a self-contained HTML page with its styling in the file. You can edit the text and layout directly in a code editor.

A few things worth keeping in mind:

- Preserve the relative folder structure so the fonts and logos continue to load.
- The page is designed to adapt to narrower screens, but check the layout at the size and aspect ratio required by your presentation or submission.
- If you revise a method, study detail, or claim, check it against the manuscript first. In particular, keep the distinction between forecast-error prediction and weather forecasting clear.
- Before sharing a revised copy, open it in a browser and check the full page. Do not rely on the code alone to judge spacing, line breaks, or readability.
